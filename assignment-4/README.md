# Assignment 4 - Preserving Privacy

## Topics Covered

Web Browsing History, Logs, HTTP Headers, Fingerprinting, Session Cookies, Tracking Cookies, Tracking Parameters, Third-Party Cookies, Private Browsing, Supercookies, DNS, DNS over HTTPS (DoH), DNS over TLS (DoT), VPN, Tor, Permissions, Location-Based Services.

## Summary

This assignment addresses privacy on the web, focusing on how users are tracked across sites and sessions, and the tools available to limit that tracking. It covers the role of cookies, tracking parameters, and browser fingerprinting in building user profiles, as well as the limitations of private browsing mode. It also introduces DNS-level privacy protections (DoH, DoT), VPNs, and Tor as mechanisms for concealing browsing activity, alongside app permissions and location-based services as privacy considerations on mobile devices.

## Key Takeaways

- Private browsing prevents local storage of history but does not stop tracking by websites, ISPs, or third-party trackers.
- Third-party cookies and tracking parameters allow advertisers to build cross-site profiles of user behavior.
- Browser fingerprinting can identify a user even without cookies, based on device and configuration characteristics.
- DNS over HTTPS and DNS over TLS encrypt DNS queries, preventing ISPs and network observers from seeing which domains a user visits.
- VPNs shift trust from the local network to the VPN provider, while Tor distributes trust across multiple relays for stronger anonymity.
