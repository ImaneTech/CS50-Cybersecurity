# Assignment 0 - Securing Accounts

## Topics Covered

Authentication, Authorization, Usernames, Passwords, Dictionary Attacks, Brute-Force Attacks, Two-Factor Authentication (2FA), Multi-Factor Authentication (Knowledge / Possession / Inherence), One-Time Password (OTP), SIM Swapping, Keylogging, Credential Stuffing, Social Engineering, Phishing, Machine-in-the-Middle Attacks, Single Sign-On (SSO), Password Managers, Passkeys.

## Summary

This assignment covers the fundamentals of account security, focusing on how identity is verified and protected in modern systems. It examines the difference between authentication and authorization, common attack vectors used to compromise credentials (dictionary attacks, brute-force attacks, credential stuffing, phishing, and SIM swapping), and the defenses used to counter them, including two-factor and multi-factor authentication, password managers, and passkeys as a password-less alternative.

## Key Takeaways

- Strong authentication relies on combining multiple factors (something you know, have, or are) rather than a password alone.
- Credential-based attacks (dictionary, brute-force, credential stuffing) exploit weak or reused passwords, making unique, high-entropy passwords and password managers essential.
- Social engineering and phishing remain effective attack vectors because they target human behavior rather than technical weaknesses.
- Passkeys and hardware-based 2FA significantly reduce the risk of account takeover compared to SMS-based OTPs, which are vulnerable to SIM swapping.
